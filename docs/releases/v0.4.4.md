# v0.4.4 — Dataset dates and clearer endpoint readings

This release includes the work committed for v0.4.3, which was not published.
Changes below are relative to the last published release, v0.4.2.

## Changes

- Refresh each monitor dataset's `DateEnded` at publication time, including
  cycles without a new probe result. The date now describes the data set sent
  in that cycle rather than the time of its last changed reading.
- Make BLE metric status text identify the selected metric and its last
  observed value for the data set, with physical unit, encoded sample, scale
  and offset. The compact status no longer repeats the full decoded packet.
- Label BLE listen output as advertisements captured during the scan. Label DNS
  addresses as those resolved during the check. Label Nmap's conclusion and
  scan details separately. These labels clarify what the saved text describes.
- Align endpoint diagnostic fixtures and documentation with NetworkMonitorLib.
- Bump the firmware version from 0.4.3 to 0.4.4. No v0.4.3 GitHub release was
  created.

## Validation

- Signed ESP-IDF v6.1 application built for ESP32-S3. The signed image's RSA
  signature was verified with the existing OTA key and the staged SHA-256
  matched its filename.
- All 35 native CTest targets passed. Python tooling ran 53 tests with one
  skipped and no failures.
- No physical board was flashed as part of this release preparation.

## Installation and source

The signed application asset named `networkmonitor-esp32-s3-0.4.4-<sha256>.bin`
is for OTA on an enrolled ESP32-S3. It preserves the device's existing
configuration and enrollment. Copy the filename unchanged into the Service
firmware volume. Staging or downloading the image does not trigger an update.

The separate `networkmonitor-esp32-s3-live-factory-0.4.4.bin` image is for
first installation on the tested ESP32-S3 with 16 MB flash and 8 MB octal
PSRAM. It uses the public Live configuration and starts serial Wi-Fi setup and
browser enrollment. Factory flashing replaces existing device configuration;
do not use this image for OTA. Verify both downloads with `SHA256SUMS.txt`.

The project source is GPL-3.0-only with separately licensed dependencies.
Matching source is the immutable [v0.4.4 tag](https://github.com/Mungert69/NetworkMonitorProcessorAgentEmbedded/tree/v0.4.4).
Clone with `--recurse-submodules`; GitHub's source archive omits submodule
contents. The attached CycloneDX SBOM and third-party notices identify pinned
dependencies and their license terms. No signing key, credentials, or enrolled
device flash is included.
